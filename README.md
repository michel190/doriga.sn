# Doriga Collection — site vitrine

Prêt-à-porter et sur mesure · Sicap Baobab, Dakar · Expédition partout dans le monde.

## Contenu
- `index.html` — la page
- `app.js` — collection, filtres, recherche, fiches robes, quiz, menu mobile
- `img/` — photos des robes (une robe = `robe-<nom>-face.jpg`, `robe-<nom>-pose.jpg`, `robe-<nom>-dos.jpg`)

## Ajouter une photo manquante
Déposer le fichier dans `img/` avec le nom prévu (ex. `robe-bleue-face.jpg`) : la robe apparaît automatiquement.

## Mise en ligne (GitHub Pages)
Settings → Pages → Source : « Deploy from a branch » → branche `main`, dossier `/ (root)`.
